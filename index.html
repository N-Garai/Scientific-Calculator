How to use it

  • Type expressions the same way as an fx-82MS. The formula stays on the top line; press = for the result.
  • SHIFT unlocks yellow labels (sin⁻¹, π, x!, 10ˣ, eˣ, nPr, Rec, %…).
  • ALPHA recalls variables A–F, M, X, Y printed in red. SHIFT RCL is STO.
  • MODE cycles COMP / SD, then Deg·Rad·Gra, then Fix·Sci·Norm. Or tap the on-screen setup chips.
  • In SD mode, M+ becomes DT (store a data point). SHIFT 1–6 recall Σx², Σx, n, x̄, σn, σn−1.
  • Keyboard: digits, + − * /, Enter, Backspace, Esc, arrows for replay/cursor, P for π.
